# 地震防災対策特別措置法の一部を改正する法律案

## 概要と経緯

<!-- llm:begin -->
**提出理由**: 地震防災対策特別措置法の実施の状況に鑑み、地震防災緊急事業に係る国の負担又は補助の特例等の措置の有効期限を延長する必要があるとされた[^1]。

**主な内容**
- 地震防災緊急事業に係る国の負担又は補助の特例等の措置の有効期限を令和13年３月31日まで延長する（附則第２項関係）[^2]。
- 公布の日から施行する[^3]。
- 令和八年度における地震防災緊急事業に係る国の負担又は補助の総額は、約四千五百六十億円となる見込みとされた[^4]。

**審議の経過**
- 2026-03-12 衆議院で受理（提出者: 災害対策特別委員長）。
- 2026-03-13 衆議院本会議で可決（賛成: 自由民主党・無所属の会、中道改革連合・無所属、日本維新の会、国民民主党・無所属クラブ、参政党、チームみらい、日本共産党／反対: 記録なし）。同日、参議院で受理。
- 2026-03-30 参議院災害対策及び東日本大震災復興特別委員会に付託。
- 2026-03-31 参議院委員会、続いて本会議で可決。

**結果**: 2026-03-31 成立、同日公布（令和八年法律第四号）。
