官報 PDF・Word 変換比較レポート

1. ZIPをすべて展開します。ZIP内からHTMLだけを取り出さないでください。
2. 展開したフォルダー内の index.html をダブルクリックします。
3. 上部の「比較する官報」で対象を選びます。
4. 左に原本PDF、右にDOCXをPDF化したプレビューを表示します。
5. OCR OFF／ONを切り替えると、右側の変換結果が切り替わります。

閲覧用のサーバー、インストール、インターネット接続は不要です。
最新のChrome、Edge、Safariなどのデスクトップブラウザーで開いてください。
HTMLがテキストとして開く場合は「このアプリケーションで開く」からブラウザーを選びます。

各欄のページ番号・矢印で移動できます。拡大・縮小・幅合わせにも対応しています。
原本とDOCXでは改ページが異なるため、初期設定では別々にページ移動します。
「ページ番号を連動」をONにすると同じ番号へ移動します。
相手側のページが少ない場合は、その最終ページを表示します。
OCR切り替え時は右側を1ページ目に戻します。

「DOCX ↓」で選択中のOCR条件のWordファイルを保存できます。
filesフォルダーには全原本と、OCR OFF／ONのDOCX・PDFを収録しています。
dataとassetsフォルダーもHTMLの表示に必要です。フォルダー構成は変更しないでください。

対象：Excelの「官報PDF」列の18件＋No.10記載法令の原本3ページ、全21原本・185ページ。
No.10は記載法令とリンク先の内容が異なるため、リンク先と記載法令の各ページを別項目にしています。
Excelの指定済PDF・RTFは変換元に使用していません。

表示するDOCXは、現在のkanpo-docxで実際に生成した結果です。
OCR OFFはPDFの文字情報と元画像を保持します。ONは帳票などの画像をNDLOCRで認識した結果も加えて変換します。
元画像は両モードで保持します。OCRで本文が増えた場合など、元の位置に対応できない画像は、元ページ番号を示す付録に掲載します。
大きな画像や複雑な表は、本文との区切りでページを分けて配置する場合があります。
認識対象の画像がない原本では、ON／OFFを切り替えても本文に差がない場合があります。
OCRの誤認識は正解原稿などで修正していません。原本と照らして確認してください。
右側のPDFは、そのDOCXをLibreOfficeでPDF化しています。
Microsoft Wordで開いたときは、フォントやアプリの違いにより表示が異なる場合があります。
PDFプレビューとDOCXの文字照合に差がある原稿は、比較画面に注記します。同梱DOCXも併せてご確認ください。
このレポートは変換結果を比較するためのものです。変換の完全性やOCR精度の認定ではありません。

manifest.json：各原本・生成結果のSHA-256と作成条件。
