# 「『届出事項（非課税口座開設届出書に記載された事項等）を提供する場合におけるレコードの内容及び記録要領等の制定について』の一部改正について」（法令解釈通達）に対する意見公募について

## 概要と結果

<!-- llm:begin -->
**何の案か**: 国税庁が、金融商品取引業者等の営業所の長が税務署長に提供すべき事項等のレコードの内容及び記録要領を定めた法令解釈通達を一部改正する案[^1]。

**意見募集**: 募集期間は一覧・抜粋とも記載がなく確認できない。結果公示は 2026-10-20、意見は 0 件。

**主な意見と考え方**
- 意見は 0 件で、意見に対する考え方は収録資料からは確認できない。

**案の修正**: 収録資料（概要）からは、案の修正の有無は確認できない。

**改正の趣旨**: 所得税法等の一部を改正する法律の施行等に伴い、所要の整備を行うものとされた[^2]。主な改正点は、租税特別措置法の一部改正に伴うレコードの内容及び記録要領の所要の改正である[^3][^4]。

[^1]: [pubcomment:410080067#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000322499) 「租税特別措置法の一部改正に伴う、金融商品取引業者等の営業所の長が当該営」
[^2]: [pubcomment:410080067#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000322499) 「等の施行等に伴い、所要の整備を行うものです」
[^3]: [pubcomment:410080067#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000322499) 「租税特別措置法の一部改正に伴う、金融商品取引業者等の営業所の長が当該営」
[^4]: [pubcomment:410080067#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000322499) 「業所の所在地の所轄税務署長に提供すべき事項等のレコードの内容及び記録要」
