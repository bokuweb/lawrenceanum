# 防災庁設置法及び防災庁設置法の施行に伴う関係法律の整備等に関する法律等の施行に伴う内閣府本府関係内閣府令の整備等に関する内閣府令（令和８年内閣府令第93号）

## 概要と結果

<!-- llm:begin -->
**何の案か**: 防災庁設置法（令和８年法律第61号）などの施行に伴い、内閣府本府関係の内閣府令を整備する内閣府令（令和８年内閣府令第93号）。収録された抜粋は災害救助法施行規則と内閣府所管旅費取扱規則の改正部分の冒頭までで、全体の改正内容は確認できない。

**意見募集**: 募集期間は収録されておらず、結果公示は 2026-10-30、意見は 0 件と記録されている。

**主な改正点**
- 災害救助法施行規則第四条の二の見出しは、改正前の「災害救助法施行令第四条第三号の内閣府令で定める者」から、改正後は「災害救助法施行令第四条第三号の防災庁令で定める者」に改められた[^1][^2]。
- 同条の本文も、改正前の「第四条第三号の内閣府令で定める者」が、改正後は「第四条第三号の防災庁令で定める者」とされた[^3][^4]。

**案の修正**: 意見数が 0 件であることのほか、修正の有無は収録資料から確認できない。

**その後**: 収録された抜粋からは、施行日や公布後の扱いは確認できない。

[^1]: [pubcomment:095260910#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000323425) 「災害救助法施行令第四条第三号の内閣府令で定める者」
[^2]: [pubcomment:095260910#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000323425) 「災害救助法施行令第四条第三号の防災庁令で定める者」
[^3]: [pubcomment:095260910#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000323425) 「四条第三号の内閣府令で定める者は、障害者の日常生活及び社会生活」
[^4]: [pubcomment:095260910#att0](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000323425) 「四条第三号の防災庁令で定める者は、障害者の日常生活及び社会生活」
