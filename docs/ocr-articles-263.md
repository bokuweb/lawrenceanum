# 画像本文の opt-in OCR 記事化（#263, native263av）

## 範囲
- 対象: CLI census で窓に文字層の本文が無い TOC 項目157件（`want-np88.txt`）。
- OCR: ndlocr-lite-rs 0.0.15（f97e930）、release+onnx、structure-rules=false、上流既定の閾値（検出0.25・行0.3）、辞書なし。ページは pypdfium2 で300dpi・表示の向きに描画。
- 各窓の先頭2ページ（232ページ）だけを認識した。それより後ろのページは `None`。
- OCR は明示した呼出しだけで使う。`analyze_item` は変更なし。CI・定期実行では OCR を動かさない。

## 結果（代理の判定）
判定の方法: 標題の告示配の号数（「同一一二」を含む）と、選んだ記事の「告示?第…号」が一致すれば正。「…関係」の項目は、最初の欄の名前（先頭6字）が選んだ記事の頭160字にあれば正。それ以外は目視が要る（?）。原本との全文照合ではない。e-Gov は告示配を収録しないので照合できない。

| | OCRなし | OCR（XY-cutのみ） | OCR + 号数見出しで分割 |
|---|---|---|---|
| 正 | 0 | 53 | **102** |
| 誤 | – | 62 | 21 |
| 選べない | 157 | 38 | 29 |
| 目視が要る | – | 4 | 5 |

内訳（最終）: 告示配 54/67 正、関係 48/85 正。

## 誤りの分類
1. **欄が見つからない（関係で23件）**: 破産・行旅死亡人・財団など。見出しが窓の3ページ目以降にある、または見出しが他の段の行と混ざって1行にならない。
2. **号外の柱の誤読が記事の頭に残る（約8件）**: 「(合)第…号 沓隊 彗星 日曜」など。ネイティブで読める柱を OCR が誤読し、字が一致しないので重複として除けない。
3. **段をまたぐ読み順（約5件）**: 「…除籍の一部が滅失令和8年7月28日一項の規定…」。段の間の罫は画像の中にあり、領域の枠が隣の段に届くと XY-cut で段を分けられない。
4. **隣の告示を選ぶ（告示配で7件）**: 第九条の承認（一〇九）で第十七条の指定（一一〇）を選ぶなど。該当する見出しが認識されていない、または標題で区別できない。
5. **字の誤り**: 配→記（「法務省告示記第百四十六号」）、「〇」の欠落、「一」の欠落（「第十七条第項」）。補正はしていない。

## 例
- 正: `20260716h01749 13` 日本国に帰化を許可する件（一〇七）→「法務省告示配第百七号 / 左記の者の申請に係る日本国に帰化の件は…」。
- 正: `20260723g00163 22` 教育職員免許状失効関係 →「教育職員免許状失効公告 / 教育職員免許法…」。
- 誤（2）: `20260722g00162 6` →「(合)第 9合( 沓隊 彗星 日曜 …」。
- 誤（4）: `20260721h01751 18`（一〇九）→「法務省告示配第百十号…」。

## 次の課題

- ネイティブの柱の位置にある OCR 領域を、字ではなく枠で除く（座標系を揃える必要がある）。
- 窓の全ページの OCR（未実施の918ページ）。

窓の全ページ（1150ページ）を同じ設定で認識し、OCR の記事化を直した。既定の `analyze_item` と、既定の census（3066項目）の pick は変更前後で一致した。

### 残る誤りの分類
1. **回転した縦組みの画像の誤読（告示配で約4件）**: 「法務省告示記第百五十七号」が他の行と1行に混ざる。OCR エンジンの範囲で、字で補正しない。
2. **OCR の字の誤り（関係で約3件）**: 「無縁填墓等改葬公告」（墳→填）。4字以上の語で1字違いまで許す照合を試したが、既定の census で既存の pick が3件消えたので採用しない。
3. **目次の語と本文の見出しが違う（財団関係5件）**: 目次「財団関係」、本文「工場財団」。ネイティブの本文でも選べない。語の辞書は作らない。
4. **欄見出しが無い裁判所の一覧（破産4件）**: 「次の破産事件について、以下のとおり…」で始まる7万字の1記事。語で始まる行が無い。
5. **代理判定が厳しい例（約4件）**: 項目の2つ目の語（「行旅死亡人」「懲戒処分」）の記事を選んでいて、1つ目の語の公告が本文に無い。目視では正しいものがある。

### 採用しなかった変更
- 既定の `split_listed_sections` で、同じ語の行が同じ記事に2つ以上あるときに最初の行で分ける案。census は一致したが、既存の単体テスト（同じ語の行が2つ以上なら分けない）と矛盾するので、OCR の記事化の中で同じ行の繰り返しとして扱った。


## 第3段（残り34件）
`pick_items_with_ocr`（OCR の経路だけ）: 「…関係」で選べないとき、目次の語と行頭が1字違いの行（4字以上）、または語で終わる短い見出しの行（語の2倍の字数まで）を持つ記事がちょうど1つなら採る。既定の pick は変えないので census は構成上同一。

- 財団関係 5件 → 全て正（「工場財団」）。
- 無縁墳墓等改葬 1件 → 「無縁填墓等改葬公告」の記事を分けて採る（代理判定は語の完全一致を見るので誤り扱い、目視で正）。
- 結果: 代理判定 123 → **128**（+目視1）。誤り13、選べない12、目視が要る4。

### 試して効果の無かったもの
- 段をまたいで2行をまとめた領域（OCR が各行と二重に出す）を除く: 157項目の判定は変わらず、取り消し。
- ネイティブの記事の末尾の文でない行を、ネイティブの語の枠ごと OCR の読み順へ移す: 破産の欄見出しは、複数ページを1つに組んだネイティブの記事の途中（後ろのページの公告が続く）にあって末尾に来ない。一方、別の記事の末尾の表の行（「亡失証書記号番号…」）を移してしまうので、取り消し。

### 残りの原因（調べた結果）
- 破産4件: 欄見出し「破産手続開始及び免責許可申立てに関する意見申述期間」はネイティブの字（画像の上の本文）で、前の公示の記事の末尾に付く。一覧は OCR の記事として後ろに足されるので、見出しと一覧がつながらない。ネイティブの行と OCR の領域を1つの読み順に並べる必要があり、ネイティブの記事を変えない今の設計の外。
- 告示配4件（滅失・指定暴力団）: 回転した縦組みの画像の誤読（「除篇が減失」、4万字の1記事）。エンジンの範囲。
- 改葬2件: 見出しの行が認識されていない（領域が段をまたいで混ざる）。
- 教育職員免許状・行旅死亡人など: 1つ目の語の見出しが認識されず、2つ目の語の記事を選ぶ。

## 第4段
census の入力（別の worktree の `target/census263`）が消えたので、アーカイブの `manifest.json` の目次から作り直した（項目の窓は次の項目の開始ページまで、25ページまで）。第3段の結果（判定ごと）がそのまま再現することを確かめてから進めた。

- 機関名の1字誤り（「法務省告示記第百九号」）: 見出しの号数が合い、機関名の字が1字を除いて順に現れる記事がちょうど1つなら採る → 正。
- 号数が認識されず「第」で切れた見出し（「愛知県公安委員会告示配第」）: 記事を分ける → 「盗品売買等防止団体」の告示を採る（代理判定は見出しの号数を見るので誤り扱い、目視で正）。
- 1字の機関名の号数の行（「告第13号」、前の段の「…告示第13号」の切れ端）を号数の見出しとしない（機関名は2字以上）: 号数の見出しで始まった記事の中では繰り返す見出しで分けないので、「教育職員免許状失効公告」3件が切れ端の記事に入っていた → 正。
- 「…関係」で標題の鍵で選んだ記事が目次の最初の語で始まらず、その語で始まる文でない行が全体でちょうど1つなら、その行からの記事を採る（「旅行業者営業保証金の権利実行申立てに係る公告」が OCR の記事の途中にあった）→ 正。
- 同じ選び直しで、語の後ろの半分以上（4字以上）で始まる行も採る（目次「日本弁護士連合会裁決取消訴訟の判決確定」、本文「裁決取消訴訟の判決確定の公告」）→ 目視で正（代理判定は語の完全一致を見るので誤り扱い）。2字の語の末尾1字まで許すと財団関係が崩れたので、4字以上に限る。
- ネイティブの文でない行で、そのページの続く語をつないだものであり、その真下（行の高さの2倍まで）に横に重なる画像の領域があるもの（画像の欄の上の欄見出し「破産手続開始及び免責許可申立てに関する意見申述期間」）は、その枠の領域として画像の行と同じ読み順に並べ、ネイティブの記事から除き、その行で記事を分ける。「…関係」で小見出しが並んで選べないときは、最初の語で始まる最初の記事を採る → 破産4件が正（目視でも欄見出しから一覧まで）。前回の「末尾の行だけ移す」案と違い、真下に画像の行がある行だけを移すので、ネイティブの表の行は動かない。
- 結果: 代理判定 128 → **138**。ただし新たに正になった教育職員免許状取上げ・金融商品取引業者・改葬の3件は、記事の頭に別の段の字が混ざり、目視では正しいと言い切れない（代理判定が緩い）。代理判定で誤りのまま目視で正しいものが3件。
