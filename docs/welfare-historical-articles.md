# 生活保護法第3条・第8条の補完資料

確認日：2026-10-25。判例97208の出来事の期間（2013-01-01〜2015-12-31）について調査した。

## e-Govの収録範囲

公開サイトの生活保護法 `325AC0000000144/versions.json.gz` と、e-Gov API v2 `law_revisions/325AC0000000144` は、調査時点で43件の revision_id が一致した。両方とも最古の施行日は2016-04-01。2013〜2015年の版がないのは、この法律について収集側が履歴を切り捨てたためではない。

収録されていない全体版を推測して作る代わりに、次の公的資料を条単位で照合した。

## 出典と照合結果

1. [衆議院：制定時の生活保護法（昭和25年法律第144号）](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/houritsu/00719500504144.htm)
   - 第3条は厚労省掲載本文と同じ文言。
   - 第8条第1項は「厚生大臣」。第2項は厚労省掲載本文と同じ文言（掲載上の末尾句点の差はある）。
2. [衆議院：中央省庁等改革関係法施行法（平成11年法律第160号）](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/housei/h146160.htm)
   - 第618条で生活保護法本則の「厚生大臣」を「厚生労働大臣」に置換。
   - 附則第1条の原則施行日は2001-01-06。第618条は同条ただし書の対象ではない。
3. [厚生労働省：生活保護法の本文・改正注記](https://www.mhlw.go.jp/web/t_doc?dataId=82048000&dataType=0)
   - 第3条には改正注記がない。
   - 第8条は「平一一法一六〇・一部改正」と注記されている。それ以後の改正注記はない。
4. [徳島市：生活保護法掲載PDF](https://www.city.tokushima.tokushima.jp/shisei/jorei/dokuziriyou.files/01-2_seikatuhogo.pdf)
   - PDF 3ページの第3条、4ページの第8条両項も同じ文言。第8条の改正注記も同じ。
   - 冒頭の改正一覧は平成27年法律第31号まで。ただし、この一覧だけから特定日の施行済み全文だとは判定していない。公開日を検索エンジンの表示から推定しない。

以上の照合から、**2013〜2015年の両条の文言は補完できる**と判断した。改正注記を根拠とする判断であり、全改正法を一件ずつ調べ直した全体版の復元ではない。必要に応じて原資料・官報等による追加確認を行う。

## 表示と適用範囲

- `historical-article-supplements.ts` に対象法令・条・確認対象期間・本文・出典・確認方法を保存する。
- 未特定で選定版がない場合だけ表示する。判例IDで固定せず、全ての抽出期間が確認対象期間の中に収まり、実在する日付であることを確認する。期間欠落・範囲外・逆転・別法令・未確認の条には広げない。
- 条文画面の上部で補完本文を表示し、指定項を強調する。判例詳細や比較欄でも補完資料があることを示すため、Wikiの条文リンクからも同じ資料にたどれる。
- e-Govの版ID・`versions`・`basis` は改変しない。参考版とは表示・説明を分ける。
- 事件の実際の適用時点、経過措置、法令全体の同一性、生活扶助基準の告示や金額は確定しない。
- 条文は公的資料からの転記でありLLMの要約ではない。既存の判例解説のLLM表示は維持する。
